# Testing Datasub QA site with Playwright
This project contains automated tests for Datasub QA site using Playwright test framework.

## Prerequisites

- Node.js (latest LTS version recommended)
- npm (comes with Node.js)
- Playwright Test Framework

## Installation

1. Clone the repository
2. Install dependencies: npm install

## Running Tests

These commands will run tests locally on your machine:

npx playwright test tests/homeRequestaquote.spec.ts
